## The story

> His letter arrived after the funeral.

Six words. A letter, a death, and an arrival that came too late —
the whole story is the gap between the letter and the funeral.

## How it runs

`main.py` writes the six-word story to `/output/entry.txt`:

```sh
python3 main.py
```

The program checks the story is exactly six words before writing it,
and writes no trailing newline, so the file holds the story and nothing else.
